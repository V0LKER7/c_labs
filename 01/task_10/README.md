# Задание 10. Числа в системе счисления с вводимым основанием

## Условие
Пользователь вводит основание [2..36], затем строки с целыми числами в этой системе (цифры больше 9 заглавными буквами), конец ввода строка "Stop". Найти число, максимальное по модулю, и сумму всех чисел; вывести их без ведущих нулей и в системах 9, 18, 27, 36.

## Алгоритм
- Основание читается строкой и проверяется (`strtol`, диапазон 2..36).
- Каждая строка сравнивается с "Stop"; иначе разбирается `parse_number` (необязательный минус, цифры только `0-9A-Z` меньше основания, проверка переполнения). Неверная строка пропускается с сообщением в stderr.
- Максимум по модулю хранится как исходное число, сравнение по модулю через беззнаковые значения. Сумма считается с проверкой переполнения.
- `to_base_text` переводит число в нужную систему; печатаются основания: введенное, 9, 18, 27, 36.
- Ввод длиннее 255 символов считается неверной строкой, остаток строки пропускается. Конец ввода (EOF) тоже завершает чтение.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic main.c -o prog`

## Тесты
| Ввод | Результат |
|---|---|
| `16`, `FF`, `-100`, `1A`, `Stop` | максимум по модулю `-100` (base 16), `-314` (9), `-E4` (18), `-9D` (27), `-74` (36); сумма 19 (base 16), 27 (9), 17 (18), P (27), P (36) |
| `2`, `101`, `-110`, `12`, `abc`, `Stop` | `12` и `abc` пропущены; максимум `-110` (base 2) = `-6` в остальных; сумма `-1` везде |
| `10`, `f`, `5` (без Stop, EOF) | `f` пропущено, максимум и сумма `5` |
| `10`, `Stop` | `No numbers were entered` |
| `37` | ошибка `Base must be an integer in [2, 36]` |
| `36`, `ZZZZZZZZZZZZZ`, `Stop` | ошибка `Value does not fit into long long` |

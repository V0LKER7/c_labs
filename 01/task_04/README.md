# Задание 4. Обработка текстового файла

## Условие
Аргументы: флаг и путь к входному файлу. Если после `-` или `/` идет `n` (`-nd`, `/ni` и так далее), путь к выходному файлу третий аргумент, иначе имя выходного файла получается добавлением префикса `out_` к имени входного.
`-d` удалить арабские цифры; `-i` для каждой строки число латинских букв; `-s` для каждой строки число символов кроме латинских букв, цифр и пробела; `-a` заменить не цифры их ASCII кодом в шестнадцатеричной системе.

## Алгоритм
- `parse_flag` определяет действие и наличие `n`, затем проверяется количество аргументов (3 или 4).
- Без `n` путь строится так: часть до последнего `/` или `\` сохраняется, перед именем вставляется `out_`.
- Файл читается построчно функцией `read_line` (динамический буфер, строки любой длины).
- `transform_line` по действию возвращает новую строку (удаление цифр, число в тексте или шестнадцатеричная замена), `process_file` только записывает результат и освобождает память.
- В `-a` символ перевода строки сохраняется как конец строки; коды печатаются заглавными двумя цифрами, цифры остаются как есть.
- Совпадение входного и выходного путей это ошибка.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic main.c -o prog`

## Тесты
Входной файл: `printf 'Hello World 123!\nabc,def; 45\n\nlast line 9' > in.txt`
| Команда | Содержимое выходного файла |
|---|---|
| `./prog -d in.txt` (out_in.txt) | `Hello World !` / `abc,def; ` / пустая строка / `last line ` |
| `./prog -i in.txt` | `10` / `6` / `0` / `8` |
| `./prog -s in.txt` | `1` / `2` / `0` / `0` |
| `./prog -a in.txt` | `48656C6C6F20576F726C642012321` / `6162632C6465663B2045` / пустая строка / `6C617374206C696E65209` |
| `./prog -nd in.txt res.txt` | то же, что `-d`, но в `res.txt` |
| `./prog /na in.txt res2.txt` | то же, что `-a`, но в `res2.txt` |
| `./prog -i sub/in.txt` | создается `sub/out_in.txt` |
| `./prog -d nofile.txt` | ошибка `Cannot open input file` |
| `./prog -nd in.txt` | ошибка `Usage: ...` |
| `./prog -d in.txt extra` | ошибка `Usage: ...` |
| `./prog -nx in.txt r` | ошибка `Unknown flag` |
| `./prog -nd in.txt in.txt` | ошибка `Input and output files must differ` |

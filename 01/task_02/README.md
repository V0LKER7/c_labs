# Задание 2. Константы e, pi, ln 2, sqrt 2, gamma

## Условие
Для каждой из пяти констант реализовать три способа вычисления с точностью eps (аргумент командной строки):
как предел, как сумма ряда (произведение), как решение уравнения. Продемонстрировать работу.

## Алгоритм
- Все функции имеют вид `status_t f(real eps, real *result)`, тип `real` это `long double`.
- Пределы с медленной сходимостью (e, pi, ln 2): n удваивается, остановка при `|a(2n) - a(n)| < eps`.
- Ряды: остановка, когда очередной член меньше eps (для знакочередующихся это точная оценка).
- Уравнения: метод дихотомии (`ln x = 1`, `e^x = 2`, `x^2 = 2`); для `cos x = -1` корень двойной, поэтому используется тернарный поиск минимума cos на [3, 4].
- sqrt 2: предел `x(n+1) = x(n) - x(n)^2/2 + 1`, произведение `2^(2^-k)`, остановка по остатку произведения.
- gamma: предел с биномиальными коэффициентами (m <= 50), ряд по блокам `floor(sqrt k)` с остановкой при `2/m < eps`, уравнение через произведение по простым (решето, t удваивается).
- Ограничение: eps должен быть в [1e-9, 1). Для gamma предел сходится как 1/m и ограничен потерей точности, поэтому работает только при eps порядка 1e-2. Ряд gamma требует около 4/eps^2 итераций, практичен при eps >= 1e-4.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic -O2 main.c -o prog -lm`

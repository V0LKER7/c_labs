# Задание 6. Функции с переменным числом аргументов, рекурсия, дихотомия

## Условие
1) Выпуклость многоугольника по координатам вершин. 2) Значение многочлена в точке (коэффициенты от старшей степени). 3) Числа Капрекара среди строк в системе base. 4) Среднее геометрическое (количество последний обязательный параметр). 5) Рекурсивное быстрое возведение вещественного числа в целую степень. 6) Корень уравнения методом дихотомии с указателем на функцию.

## Алгоритм
- `is_convex_polygon(&result, eps, n, x1, y1, ...)`: для каждой тройки соседних вершин считается векторное произведение; все ненулевые знаки должны совпадать, а суммарный угол поворота (через `atan2`) должен быть равен 2*pi, что отсекает самопересекающиеся фигуры (звезда).
- `evaluate_polynomial(&result, x, degree, c_n, ..., c_0)`: схема Горнера, ожидается degree+1 значений типа `double`.
- `find_kaprekar_numbers(result, &count, base, n, str1, ...)`: строка разбирается в число в системе base (своя функция, проверка цифр и переполнения). Для n^2 перебираются разбиения по степеням base: правая часть должна быть > 0 и сумма частей равна n. Число должно быть меньше 2^32.
- `geometric_mean(&result, count, ...)`: `exp(сумма логарифмов / count)`, при нуле среди чисел результат 0, отрицательные числа ошибка.
- `fast_power(&result, base, exp)`: `power(b, n) = power(b, n/2)^2` (и умножение на b при нечетном n), отрицательная степень это 1 / power; 0 в отрицательной степени ошибка.
- `find_root(&root, left, right, eps, f)`: дихотомия, проверяется смена знака на концах (иначе `ERR_INTERVAL`).
- Результаты возвращаются через параметры, статус через `status_t`. Демонстрация в `main`.

# Задание 1. Обработка числа x по флагу

## Условие
Программе подаются флаг (`-` или `/` и буква) и число x. Флаги:
`-h` кратные x числа до 100; `-p` простое или составное; `-s` цифры x в системе 16 через пробел;
`-e` таблица степеней оснований 1..10 с показателями 1..x (x <= 10); `-a` сумма 1..x; `-f` факториал x.

## Алгоритм
- Проверка количества аргументов (ровно 2), формата флага и того, что x это целое число >= 0 (`strtoull`, проверка переполнения).
- `-h`: перебор n от 1 до 100, в список попадают n с `n % x == 0`.
- `-p`: пробные деления от 2 до корня из x (условие `d <= x / d`). Число меньше 2 не простое и не составное.
- `-s`: `snprintf("%llX")`, затем вывод символов через пробел.
- `-e`: для каждого основания 1..10 печатаются степени 1..x.
- `-a`: формула x*(x+1)/2, при x > 4294967295 ошибка переполнения.
- `-f`: умножение в цикле с проверкой переполнения (максимум 20!).
- Вычисления вынесены в отдельные функции, вывод делает слой `run_*`.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic main.c -o prog`

## Тесты
| Команда | Результат |
|---|---|
| `./prog -h 7` | `7 14 21 28 35 42 49 56 63 70 77 84 91 98` |
| `./prog -h 101` | `Natural numbers up to 100 divisible by 101 do not exist` |
| `./prog -p 17` | `17 is prime` |
| `./prog -p 18` | `18 is composite` |
| `./prog -p 1` | `1 is neither prime nor composite` |
| `./prog -s 255` | `F F` |
| `./prog -s 0` | `0` |
| `./prog -e 4` | строки `1: 1 1 1 1` ... `10: 10 100 1000 10000` |
| `./prog -e 11` | ошибка `x is out of allowed range for this flag` |
| `./prog -a 100` | `5050` |
| `./prog -f 5` | `120` |
| `./prog /f 0` | `1` |
| `./prog -f 21` | ошибка `Result does not fit into the type` |
| `./prog -x 5` | ошибка `Unknown flag` |
| `./prog -p abc`, `./prog -p -5` | ошибка `x must be a non-negative integer` |
| `./prog`, `./prog -h` | ошибка `Usage: program <flag> <x>` |

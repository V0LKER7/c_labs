# Задание 1: флаги для числа x

## Условие

Программе подаются число x и флаг (начинается с "-" или "/"):
- `-h` натуральные числа до 100 включительно, кратные x (или сообщение, что таких нет)
- `-p` простое ли x, составное ли x
- `-s` цифры x в системе счисления 16 через пробел, от старших к младшим, без ведущих нулей
- `-e` таблица степеней оснований 1..10 для показателей 1..x (x не больше 10)
- `-a` сумма натуральных чисел от 1 до x
- `-f` факториал x

## Алгоритм

1. Проверяется количество аргументов (ровно 2), x и флаг могут идти в любом порядке.
2. x разбирается вручную в `uint64_t` с проверкой символов и переполнения.
3. `-h`: цикл `x, 2x, 3x, ...` пока значение не больше 100.
4. `-p`: x меньше 2 не простое и не составное; чётные обрабатываются отдельно; нечётные делители проверяются до корня через условие `d <= x / d` (без переполнения).
5. `-s`: x делится на 16, остатки собираются и выводятся в обратном порядке; для 0 выводится "0".
6. `-e`: x должен быть в диапазоне 1..10; степени считаются умножением с проверкой переполнения.
7. `-a`: считается `x(x+1)/2`, чётный множитель делится заранее, затем проверяется переполнение.
8. `-f`: цикл умножения с проверкой переполнения (максимум 20!).
9. Вычисления в функциях `find_multiples`, `classify_number` и т.д. возвращают `status_t`; печать только в `run_*`.

## Сборка

```
gcc -std=c99 -Wall -Wextra -pedantic -o task01 main.c
```

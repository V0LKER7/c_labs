# Задание 9. Массивы и псевдослучайные числа

## Условие
1) Заполнить массив фиксированного размера случайными числами из [a, b] (a, b аргументы командной строки), за один проход найти минимум и максимум и поменять их местами. 2) Заполнить динамические массивы A и B случайного размера из [10..10000] числами из [-1000..1000]; построить C, где C[i] = A[i] + ближайший по значению к A[i] элемент B.

## Алгоритм
- Аргументов ровно 2, оба целые, a <= b и размах помещается в `RAND_MAX`.
- `random_in_range(low, high) = low + rand() % (high - low + 1)`, `srand(time)`.
- `swap_min_and_max`: один цикл хранит индексы минимума и максимума, после цикла элементы меняются местами.
- `closest_value`: линейный проход по B с минимальным модулем разности; `build_sum_array` формирует C. Сложность O(|A| * |B|), не более 10^8 операций.
- Память проверяется на каждом выделении и освобождается в одном месте.
- Для массивов A, B, C выводятся размеры и первые 8 элементов.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic main.c -o prog`

## Тесты
`./prog -50 50` (значения случайны, пример):
```
fixed array before (20 elements): 30 -28 -22 -27 -19 4 47 39 -32 34 25 -32 34 -41 -48 23 -18 -49 -27 5
fixed array after  (20 elements): 30 -28 -22 -27 -19 4 -49 39 -32 34 25 -32 34 -41 -48 23 -18 47 -27 5
A (9233 elements): -270 0 -26 281 -918 887 -810 714 ...
B (8757 elements): 579 354 16 304 842 514 -354 296 ...
C (9233 elements): -540 0 -52 562 -1836 1774 -1620 1428 ...
```
Видно, что 47 (максимум) и -49 (минимум) поменялись местами. C[1] = 0 + 0, так как в B есть 0 (ближайший к A[1]).
| Команда | Результат |
|---|---|
| `./prog 5 1` | ошибка `Need a <= b and b - a + 1 <= RAND_MAX` |
| `./prog a 1` | ошибка `a and b must be integers` |
| `./prog 3` | ошибка `Usage: program <a> <b>` |

# Задание 9: массивы и псевдослучайные числа

## Условие

1. Заполнить массив фиксированного размера (20) псевдослучайными числами из [a..b] (a и b аргументы командной строки), найти минимум и максимум и поменять их местами за один проход.
2. Заполнить динамические массивы A и B псевдослучайного размера из [10..10000] числами из [-1000..1000]; построить массив C, где C[i] = A[i] + ближайший по значению к A[i] элемент B.

## Алгоритм

1. Аргументы a и b разбираются через `strtoll`, проверяется `a <= b` и ограничение по модулю 10^9 (чтобы размах не переполнял int).
2. `fill_random` использует `rand()` с масштабированием дробью, поэтому работает при любом `RAND_MAX`.
3. `swap_min_max` за один цикл запоминает индексы минимума и максимума, затем меняет элементы.
4. `build_sum_with_nearest` для каждого `A[i]` линейно ищет элемент B с минимальным `|B[j] - A[i]|`, сложность O(|A| * |B|), не больше 10^8 операций.
5. Память выделяется через `malloc` с проверкой, освобождается в одной точке выхода из функции.
6. Для массивов 9.2 печатаются размеры и первые 10 элементов.

## Сборка

```
gcc -std=c99 -Wall -Wextra -pedantic -o task09 main.c
```

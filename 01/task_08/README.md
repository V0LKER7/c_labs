# Задание 8: минимальное основание системы счисления

## Условие

В файле числа записаны в разных системах счисления (2..36), основание утеряно. Для каждого числа определить минимальное основание, в котором запись корректна, и построчно вывести: число без ведущих нулей, основание, значение в десятичной системе. Регистр букв не важен.

## Алгоритм

1. Аргументы: входной и выходной файлы.
2. Лексемы читаются динамическим буфером.
3. `analyze_number`: приводит буквы к верхнему регистру, учитывает необязательный "-", находит максимальную цифру (минимальное основание = max + 1, но не меньше 2), пропускает ведущие нули (число из одних нулей даёт "0"), считает значение в `uint64_t` с проверкой переполнения.
4. Некорректная лексема или переполнение прекращают обработку с сообщением (плохая лексема печатается в stderr).

## Сборка

```
gcc -std=c99 -Wall -Wextra -pedantic -o task08 main.c
```

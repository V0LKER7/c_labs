# Задание 8. Минимальное основание системы счисления

## Условие
Во входном файле (argv[1]) числа в системах счисления [2..36], основание неизвестно. Для каждого числа вывести в выходной файл (argv[2]) строку: число без ведущих нулей, минимальное допустимое основание, значение в системе 10. Регистр букв не важен.

## Алгоритм
- Лексемы читаются `read_lexeme` (разделители: пробел, табуляция, перевод строки).
- `analyze_number`: допускается знак, каждая цифра проверяется (`0-9`, `a-z` без учета регистра), по максимальной цифре определяется основание `max_digit + 1` (не меньше 2), ведущие нули отбрасываются (число `000` дает `0`).
- `to_decimal` переводит в `long long` с проверкой переполнения.
- Запись строки `<число заглавными> <основание> <значение>`.
- Недопустимый символ в числе или переполнение это ошибка с сообщением.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic main.c -o prog`

## Тесты
Вход: `printf '000 1A\nff  -zz\n  0012 7\t+101 Z\n' > in.txt`, команда `./prog in.txt out.txt`, содержимое out.txt:
```
0 2 0
1A 11 21
FF 16 255
-ZZ 36 -1295
12 3 5
7 8 7
101 2 5
Z 36 35
```
| Команда | Результат |
|---|---|
| файл `12 ab#` | ошибка `Input contains an invalid number` |
| файл `99999999999999999999` | ошибка `Number does not fit into long long` |
| `./prog in.txt in.txt` | ошибка `Input and output files must differ` |
| `./prog` | ошибка `Usage: program <input> <output>` |
| `./prog nofile o` | ошибка `Cannot open file` |

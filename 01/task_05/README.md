# Задание 5: суммы рядов и интегралы

## Условие

Вычислить с точностью eps суммы:
a. сумма x^n / n!
b. сумма (-1)^n x^(2n) / (2n)!
c. сумма 3^(3n) (n!)^3 x^(2n) / (3n)!
d. сумма (-1)^n (2n-1)!! x^(2n) / (2n)!!, n от 1

и интегралы по [0, 1]: a. ln(1+x)/x, b. e^(-x^2/2), c. ln(1/(1-x)), d. x^x.

Программа получает eps и x (x нужен для сумм, должно быть |x| < 1, при этом ряды c и d сходятся).

## Алгоритм

1. Каждый ряд задан функцией отношения соседних слагаемых `ratio(n, x)`, поэтому факториалы не вычисляются.
2. `sum_series` умножает текущее слагаемое на `ratio`, суммирует и останавливается, когда `|term| < eps` и отношение следующих слагаемых по модулю меньше 1.
3. Интегралы считаются формулой средних прямоугольников; число отрезков удваивается, пока `|I(2n) - I(n)| < eps`. Метод не вычисляет функцию в концах отрезка, поэтому особенности в 0 (a, d) и в 1 (c) не мешают.
4. При превышении лимита итераций печатается "no convergence for this epsilon".

Эталонные значения для проверки: e^0.5 = 1.6487212707, cos 0.5 = 0.8775825619, 1/sqrt(1 + x^2) - 1 при x = 0.5 равно -0.1055728090, интегралы: pi^2/12 = 0.8224670334, 0.8556243919, 1, 0.7834305107.

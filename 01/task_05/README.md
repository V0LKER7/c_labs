# Задание 5. Суммы рядов и интегралы с точностью eps

## Условие
По eps и x вычислить суммы: a) x^n/n!; b) (-1)^n x^(2n)/(2n)!; c) 3^(3n)(n!)^3 x^(2n)/(3n)!; d) (-1)^n (2n-1)!! x^(2n)/(2n)!! (n от 1).
По eps вычислить интегралы по [0, 1]: a) ln(1+x)/x; b) e^(-x^2/2); c) ln(1/(1-x)); d) x^x.

## Алгоритм
- Аргументы: ровно 2 (`eps` в [1e-12, 1) и `x`).
- Ряды: каждый следующий член получается из предыдущего умножением на отношение (без факториалов), суммирование до `|член| < eps`. Для c и d требуется `|x| < 1`, иначе сообщение о расходимости; число членов ограничено.
- Интегралы: правило средних прямоугольников. Число отрезков удваивается, остановка при `|I(2n) - I(n)| < eps` (правило Рунге). Концы отрезка не вычисляются, поэтому особенности в 0 и 1 не мешают.
- Лимит 2^26 отрезков, иначе сообщение `no convergence`.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic -O2 main.c -o prog -lm`

## Тесты
`./prog 1e-6 0.5`:
```
1a   1.6487212650
1b   0.8775825622
1c   2.9004873891
1d   -0.1055729447
2a   0.8224668383
2b   0.8556244883
2c   0.9999993390
2d   0.7834301444
```
Эталон: e^0.5 = 1.6487212707, cos 0.5 = 0.8775825619, 1c = 2.9004876514, 1d = 1/sqrt(1.25) - 1 = -0.1055728090, интегралы: pi^2/12 = 0.8224670334, 0.8556243918, 1, 0.7834305107.
| Команда | Результат |
|---|---|
| `./prog 1e-6 2` | 1a = 7.3890560703, 1b = -0.4161468396, 1c и 1d: `series diverges for this x` |
| `./prog 1e-9 0.9` | 1a = 2.4596031111, 1b = 0.6216099683, 2c: `no convergence` |
| `./prog 1e-6` | ошибка `Usage: program <eps> <x>` |
| `./prog 5 1` | ошибка `eps must be a number in [1e-12, 1)` |
| `./prog 1e-6 abc` | ошибка `x must be a number` |

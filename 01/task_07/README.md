# Задание 7: слияние файлов и преобразование лексем

## Условие

Флаг и пути к файлам:
- `-r file1 file2 out`: лексемы из file1 и file2 чередуются (нечётные позиции из file1, чётные из file2); когда один файл закончился, дописываются остальные лексемы другого
- `-a in out`: в каждой десятой лексеме буквы переводятся в нижний регистр, затем все символы заменяются ASCII-кодами в системе 4; в каждой второй (не десятой) буквы переводятся в нижний регистр; в каждой пятой (не десятой) все символы заменяются ASCII-кодами в системе 8

Лексемы разделены любым количеством пробелов, табуляций, переводов строк; в выходе лексемы разделены одним пробелом.

## Алгоритм

1. Проверяется количество аргументов: 5 для `-r`, 4 для `-a`; выходной путь не должен совпадать с входными.
2. `read_token` читает лексему в динамически растущий буфер (длина не ограничена).
3. `-r`: в цикле по очереди читается лексема из каждого открытого файла; закончившийся файл помечается закрытым, второй продолжает работать.
4. `-a`: для лексемы с номером i порядок проверок: `i % 10 == 0`, затем `i % 2 == 0`, затем `i % 5 == 0`; `transform_token` пишет результат в рабочий буфер размером `4 * длина + 1` (код символа в системе 4 занимает до 4 цифр).
5. Запись лексем и пробелов-разделителей вынесена в `write_token`.

## Сборка

```
gcc -std=c99 -Wall -Wextra -pedantic -o task07 main.c
```

## Тесты

Входные файлы лежат в `tests/`: `f1.txt` = `a1  b2<TAB>c3<LF>d4 e5`, `f2.txt` = `X Y Z W` с лишними пробелами, `text.txt` с 11 лексемами.

```
$ ./task07 -r f1.txt f2.txt out.txt
[out.txt]
a1 X b2 Y c3 Z d4 W e5
```

```
$ ./task07 /a text.txt out.txt
[out.txt]
one two THREE four 106151166145 six seven eight nine 131012111232 eleven
```

```
$ ./task07 -r f1.txt f2.txt
stderr: Error: wrong number of arguments for this flag
```

```
$ ./task07 -a text.txt
stderr: Error: wrong number of arguments for this flag
```

```
$ ./task07 -x a b
stderr: Error: unknown flag
```

```
$ ./task07 -a missing.txt out.txt

```


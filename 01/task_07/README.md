# Задание 7. Работа с лексемами двух файлов

## Условие
Флаг и пути к файлам. `-r file1 file2 out`: записать в out лексемы file1 и file2 поочередно (нечетные позиции из file1, четные из file2), когда один файл кончился, дописать остаток другого. `-a in out`: в каждой 10-й лексеме перевести буквы в строчные, затем все символы в ASCII коды в системе 4; в каждой 2-й (не 10-й) перевести буквы в строчные; в каждой 5-й (не 10-й) все символы заменить ASCII кодами в системе 8. Лексемы разделяются пробелами, табуляциями и переводами строк; в выходном файле одним пробелом.

## Алгоритм
- Количество аргументов: `-r` 5, `-a` 4; выходной файл не должен совпадать с входными.
- `read_lexeme` пропускает разделители и читает слово в динамический буфер.
- `-r`: переменная `turn` чередует источники, ended[] отмечает закончившиеся файлы, цикл идет пока не закончены оба.
- `-a`: счетчик лексем с 1; `index % 10`, затем `% 2`, затем `% 5` определяют преобразование (пересечений 2 и 5 без 10 не бывает).
- Код символа переводится в систему 4 или 8 функцией `number_to_base`.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic main.c -o prog`

## Тесты
Файлы: `printf 'a b  c\nd\te\n' > f1.txt`, `printf '1 2 3 4 5 6\n7' > f2.txt`
| Команда | Результат |
|---|---|
| `./prog -r f1.txt f2.txt out.txt` | `a 1 b 2 c 3 d 4 e 5 6 7` |
| `./prog -r f2.txt f1.txt out.txt` | `1 a 2 b 3 c 4 d 5 e 6 7` |
| `./prog -a in.txt out2.txt`, in.txt = `Hello World ABC xyz Q r12 Ab C d eF gH` + `ij KL` на второй строке | `Hello world ABC xyz 121 r12 Ab c d 12111212 gH ij KL` |
| пустой входной файл с `-a` | пустая строка |
| `./prog -a in.txt in.txt` | ошибка `Output file must differ from input files` |
| `./prog -r f1.txt f2.txt` | ошибка `Wrong number of arguments for this flag` |
| `./prog -a nofile out` | ошибка `Cannot open file` |
| `./prog -q a b` | ошибка `Unknown flag` |

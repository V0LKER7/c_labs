# Задание 6. overfscanf и oversscanf

## Условие
Аналоги fscanf и sscanf с дополнительными флагами:
- %Ro римское число в int
- %Zr цекендорфово представление в unsigned int
- %Cv и %CV число в системе с основанием в int (параметры: int *, основание; основание вне [2..36] заменяется на 10; буквы строчные или заглавные)

Валидация входного потока не требуется.

## Алгоритм
- Источник данных обёрнут в Source (FILE * или строка с позицией), есть source_get и source_unget, поэтому один код работает для файла и строки.
- scan_source идёт по формату: пробел пропускает пробелы входа, обычный символ должен совпасть, %% читает литерал %.
- Кастомные флаги читаются собственными функциями:
  - Ro: набор символов IVXLCDM, обход справа налево (меньшее перед большим вычитается)
  - Zr: читаются биты до двух единиц подряд, сумма чисел Фибоначчи на позициях единиц
  - Cv и CV: знак, затем цифры допустимые для основания (строчные для Cv, заглавные для CV)
- Стандартные спецификаторы делегируются fscanf или sscanf (для строки с добавлением %n для сдвига позиции). Подавление присваивания (*) и %n не поддерживаются.
- Возврат: число успешно присвоенных значений.
- Ограничение: цекендорфово представление нуля ("01") не читается.

Сборка: `gcc -std=c99 -Wall -Wextra -pedantic -o main main.c -lm`

## Тесты (вывод ./main)
```
sscanf: count=5 roman=14 zeckendorf=9 hex=255 decimal=42 word=hello
sscanf: count=4 roman=1994 zeckendorf=4 base36 lower=-1295 upper=1295
sscanf invalid roman: count=0
sscanf bases: count=3 bin=5 oct=511 default10=12
fscanf: count=4 roman=444 zeckendorf=33 hex=127 real=3.5
```
Входы: "XIV 100011 ff 42 hello", "MCMXCIV 1011 -zz ZZ", "abc", "101 777 12" (основания 2, 8, 99), файл "CDXLIV 10101011 7F 3.5".

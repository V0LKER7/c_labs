# Задание 6. overfscanf и oversscanf

## Условие
Функции с прототипом как у `fscanf` и `sscanf` плюс флаги: `%Ro` римское число в `int`; `%Zr` цекендорфово представление в `unsigned int`; `%Cv` и `%CV` целое в системе счисления с основанием (первый аргумент `int *`, второй основание 2..36, иначе 10), буквы строчные и заглавные. Валидация входного потока не требуется.

## Алгоритм
- Источник данных абстрагирован структурой `source_t` (`FILE *` или строка с позицией): `peek`, `advance`, пропуск пробелов.
- Формат обходится посимвольно: пробел пропускает пробелы входа, обычный символ должен совпасть, `%` обрабатывается как спецификация.
- Пользовательские флаги разбираются своими функциями:
  - `%Ro` читает буквы `IVXLCDM`, затем считает справа налево (меньшая цифра перед большей вычитается).
  - `%Zr` читает биты, веса 1, 2, 3, 5, 8, ...; две подряд идущие единицы означают конец записи, последняя единица в значение не входит.
  - `%Cv`, `%CV` читают знак и цифры нужного регистра.
- Стандартные флаги: спецификация копируется в строку, добавляется `%n` и вызывается настоящий `fscanf` или `sscanf` для одного преобразования. По `%n` определяется число прочитанных символов, позиция строки сдвигается.
- Возврат как у `scanf`: число присвоенных значений, `EOF` при конце данных до первого присваивания.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic -o task6 main.c`

## Тесты (вывод `./task6`)
```
assigned: 6
roman=1994 zeckendorf=9 lower=-255 upper=127 plain=42 word=hello
assigned: 2 binary=11 invalid_base_as_10=77
assigned: 1 literal_match_roman=42
no roman digits: 0
empty input: -1
file assigned: 5 roman=2026 zeckendorf=4 base36=1295 real=3.5 tail=end
```
Входы: `"MCMXCIV 100011 -ff 7F 42 hello"` с форматом `"%Ro %Zr %Cv %CV %d %31s"`, `"1011 77"` с `"%Cv %Cv"` (основания 2 и 99), `"x=XLII;"` с `"x=%Ro;"`, последняя строка читается из временного файла через `overfscanf`.

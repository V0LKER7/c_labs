# Задание 8. Сумма больших чисел в системе счисления

## Условие
Функция с переменным числом аргументов суммирует неотрицательные целые числа в системе с основанием [2..36]. Параметры: основание, количество чисел, строковые представления. Числа могут не помещаться в встроенные типы, поэтому реализуется сложение в столбик. Результат без ведущих нулей.

## Алгоритм
- add_in_columns(left, right, base, &result): проверка символов (цифры строго меньше основания, регистр любой), сложение с конца по разрядам с переносом, в буфер записывается в обратном порядке, убираются ведущие нули, строка разворачивается. Результат в верхнем регистре.
- sum_in_base(base, count, &result, ...): накопитель начинается с "0", для каждого числа из va_arg вызывается add_in_columns, старый накопитель освобождается.

Сборка: `gcc -std=c99 -Wall -Wextra -pedantic -o main main.c -lm`

## Тесты (вывод ./main)
```
base 16: FF + 1 + abc = BBC
base 2: 0011 + 0001 = 100
base 10: 99999999999999999999999999 + 1 = 100000000000000000000000000
base 36: Z + 1 = 10
base 10: 000 + 00 + 0 = 0
base 2: 101 + 102: error 4   (недопустимая цифра)
base 1: error 3              (недопустимое основание)
```

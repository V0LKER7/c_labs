# Задание 8. Сумма чисел в системе счисления

## Условие
Функция с переменным числом аргументов складывает неотрицательные целые числа, заданные строками в системе с основанием 2..36. Числа могут не помещаться во встроенные типы, поэтому нужна функция сложения "в столбик". В результате нет ведущих нулей.

## Алгоритм
- `add_in_columns(left, right, base, &result)`: проверка цифр, затем проход с младших разрядов с переносом, лишний перенос добавляется в конец, ведущие нули отбрасываются, строка разворачивается. Результат в заглавных буквах.
- `sum_in_base(&result, base, count, s1, ..., sk)`: накопитель начинается с `"0"`, на каждом шаге `total = add_in_columns(total, s_i)`.
- Ошибки: основание вне 2..36, недопустимая цифра, пустая строка, `NULL`, нехватка памяти.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic -o task8 main.c`

## Тесты (вывод `./task8`)
| Операция | Результат |
|---|---|
| base 16: `FF + 1 + a0` | `1A0` |
| base 2: `1010 + 0110 + 1` | `10001` |
| base 10: 32 девятки `+ 1` | `1` и 32 нуля |
| base 36: `ZZZ + 1` | `1000` |
| base 10: `000 + 0000` | `0` |
| base 8: `17 + 8` | ошибка: недопустимая цифра |
| base 40 | ошибка: основание вне диапазона |

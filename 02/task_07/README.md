# Задание 7. Самые длинные векторы по разным нормам

## Условие
Функция с переменным числом аргументов получает размерность n, векторы (структуры с координатами) и указатели на функции норм. Для каждой нормы возвращает самый длинный вектор (если таковых несколько, все). Нормы: максимум модулей, p-норма (p >= 1), норма sqrt((Ax, x)) для положительно определённой матрицы A.

## Алгоритм
- Все нормы имеют один тип указателя: Norm_function(coords, n, params, &result), параметры нормы (p или матрица) передаются отдельным аргументом void *.
- Вызов: find_longest_vectors(eps, n, vector_count, norm_count, &results, векторы..., (норма, параметры)...).
- Сначала считываются векторы (va_arg структуры по значению), затем для каждой нормы: вычисляются нормы всех векторов, находится максимум, в результат попадают индексы всех векторов, у которых максимум минус норма не больше eps (сравнение вещественных с эпсилон).
- Результат: массив Longest_result (норма и индексы), освобождается free_longest_results.
- check_positive_definite проверяет симметричность и положительную определённость матрицы разложением Холецкого.

Сборка: `gcc -std=c99 -Wall -Wextra -pedantic -o main main.c -lm`

## Тесты
Векторы: v1=(1,2,3), v2=(-4,0,1), v3=(2,-4,0), A=diag(1,2,3).
```
A positive definite: yes
Bad A positive definite: no
infinity: norm=4.0000, vectors: v2 v3
p=1: norm=6.0000, vectors: v1 v3
p=2: norm=4.4721, vectors: v3
A=diag(1,2,3): norm=6.0000, vectors: v1 v3
p=0.5 status: 3
```
Последняя строка: код STATUS_INVALID_ARGUMENT для p < 1.

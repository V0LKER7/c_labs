# Задание 7. Самые длинные векторы по нормам

## Условие
Функция с переменным числом аргументов получает размерность `n`, векторы (структуры) и указатели на функции норм. Для каждой нормы возвращается самый длинный вектор (все, если таковых несколько). Нормы: `max |x_j|`, `p`-норма (`p >= 1`), `sqrt((Ax, x))` для положительно определенной матрицы `A`.

## Алгоритм
- Все нормы имеют один тип `norm_fn_t`: `status_t f(const double *coords, size_t n, const void *params, double *result)`. Параметры нормы (`p`, матрица, эпсилон) передаются через `params`.
- `find_longest_vectors(n, vector_count, norm_count, eps, &results, v1, ..., vk, f1, params1, ..., fm, paramsm)`: сначала все аргументы считываются через `va_arg` в массивы, затем вычисления.
- Для каждой нормы считаются длины всех векторов, находится максимум, в результат попадают векторы, чья длина отличается от максимума не больше чем на `eps`.
- Результат: массив `norm_result_t` (максимум нормы, найденные векторы, их число), освобождается `free_norm_results`.
- Ошибки: `p < 1`, форма матрицы заметно меньше 0, нулевая размерность, пустые данные, нехватка памяти.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic -o task7 main.c -lm`

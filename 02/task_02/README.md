# Задание 2. Сортировка сотрудников

## Условие
Аргументы: входной файл, флаг (-a, -d, /a, /d), выходной файл. В каждой строке файла: id (целое неотрицательное), имя и фамилия (непустые, только латиница), зарплата (неотрицательное вещественное). Записи читаются в динамический массив структур Employee и выводятся отсортированными (по возрастанию или убыванию) по зарплате, затем фамилии, имени, id. Сортировка только через qsort.

## Алгоритм
- Строки читаются через fgets, пустые пропускаются, слишком длинные отвергаются.
- Строка разбирается через sscanf в токены, каждый токен проверяется: id только цифры в пределах unsigned int, имена только буквы A-Z a-z, зарплата через strtod и >= 0, лишних токенов нет.
- Массив растёт через realloc (удвоение).
- Два компаратора: compare_ascending (зарплаты сравниваются с эпсилон SALARY_EPSILON, затем strcmp по фамилии и имени, затем id) и compare_descending (вызывает первый с обратным порядком аргументов).
- Совпадение входного и выходного файла запрещено.

Сборка: `gcc -std=c99 -Wall -Wextra -pedantic -o main main.c -lm`

## Тесты
Файл in.txt:
```
1 John Smith 1500.50
2 Anna Brown 2000
3 Bob Smith 1500.50
4 Alice Smith 1500.50
5 Zed Young 100
```

`./main in.txt -a out.txt`:
```
5 Zed Young 100.00
4 Alice Smith 1500.50
3 Bob Smith 1500.50
1 John Smith 1500.50
2 Anna Brown 2000.00
```

`./main in.txt /d out.txt`:
```
2 Anna Brown 2000.00
1 John Smith 1500.50
3 Bob Smith 1500.50
4 Alice Smith 1500.50
5 Zed Young 100.00
```

Ошибки (код возврата 1):
| Случай | Сообщение |
|---|---|
| зарплата -5 в файле | Error: invalid data in input file |
| имя J0hn | Error: invalid data in input file |
| флаг -x | Error: invalid flag |
| нет входного файла | Error: cannot open input file |
| входной и выходной файл совпадают | Error: input and output files must differ |

# Задание 2. Сортировка сотрудников

## Условие
Аргументы: входной файл, флаг (`-a`, `/a`, `-d`, `/d`), выходной файл. В каждой строке: `id имя фамилия зарплата`. Записи читаются в динамический массив структур `Employee` и сортируются через `qsort` по зарплате, затем фамилии, имени, id (по возрастанию или убыванию).

## Алгоритм
- Строка читается `fgets`, пустые строки пропускаются, слишком длинная строка это ошибка.
- Токены проверяются: id только цифры без переполнения, имя и фамилия непустые из латинских букв (до 63 символов), зарплата конечное число не меньше 0, лишних токенов нет.
- Массив растет через `realloc` (удвоение).
- Компаратор по возрастанию: зарплата через `compare_double(a, b, eps)`, затем `strcmp` фамилий, имен, сравнение id. Компаратор по убыванию вызывает возрастающий с переставленными аргументами.
- Запись в выходной файл, проверка `fprintf` и `fclose`.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic -o task2 main.c -lm`

## Тесты
Входной файл `emp.txt`:
```
3 Ivan Petrov 1500.50
1 Anna Smirnova 2000
2 Boris Petrov 1500.50
4 Ivan Petrov 1500.50

5 Zoe Adams 0
```
`./task2 emp.txt -a out.txt`:
```
5 Zoe Adams 0.00
2 Boris Petrov 1500.50
3 Ivan Petrov 1500.50
4 Ivan Petrov 1500.50
1 Anna Smirnova 2000.00
```
`./task2 emp.txt /d out.txt`:
```
1 Anna Smirnova 2000.00
4 Ivan Petrov 1500.50
3 Ivan Petrov 1500.50
2 Boris Petrov 1500.50
5 Zoe Adams 0.00
```
Ошибки (код 1): отрицательная зарплата, цифра в имени, лишний токен в строке, несуществующий входной файл, флаг `-x`, неверное число аргументов.

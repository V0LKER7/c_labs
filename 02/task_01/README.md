# Задание 1. Обработка строк по флагам

## Условие
Аргументы: флаг, строка, (для -c) seed типа unsigned int и произвольное число строк.
- -l длина строки
- -r перевёрнутая строка
- -u символы на нечётных позициях в верхний регистр
- -n сначала цифры, затем буквы, затем остальные символы (порядок сохраняется)
- -c конкатенация 2-й, 4-й, 5-й и т. д. строк в псевдослучайном порядке (srand(seed))

Результаты в динамической памяти, string.h не используется.

## Алгоритм
- Для каждого флага своя функция со статус-кодом (Status) и результатом через параметр.
- -u: цикл по индексам, при i % 2 == 1 вызывается toupper.
- -n: три прохода по строке (цифры, буквы, остальное), запись в новую строку.
- -c: массив индексов строк перемешивается по Фишеру-Йетсу после srand(seed), затем строки копируются в общий буфер.
- Валидация: число аргументов, формат флага, seed (только цифры, не больше UINT_MAX).

Сборка: `gcc -std=c99 -Wall -Wextra -pedantic -o main main.c -lm`

## Тесты
| Команда | Результат |
|---|---|
| ./main -l "hello world" | 11 |
| ./main -r abcdef | fedcba |
| ./main -u abcdefgh | aBcDeFgH |
| ./main -n "a1b2-c3 d4!" | 1234abcd- ! |
| ./main -c A 5 B C D | BACD |
| ./main -c A 7 B C D | CDAB |
| ./main -l | сообщение Usage, код 1 |
| ./main -x abc | сообщение Usage, код 1 |
| ./main -c A -5 | Error: invalid argument |
| ./main -l a b | сообщение Usage, код 1 |
| ./main -l "" | 0 |

Порядок в -c зависит от реализации rand в libc.

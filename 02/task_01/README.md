# Задание 1. Обработка строк по флагу

## Условие
Аргументы: флаг, строка, для `-c` еще `unsigned int` и произвольное число строк.
- `-l` длина строки
- `-r` перевернутая строка
- `-u` символы на нечетных позициях (с 0) в верхний регистр
- `-n` сначала цифры, затем буквы, затем остальные символы (порядок сохраняется)
- `-c` конкатенация 2-й, 4-й, 5-й и т. д. строк в случайном порядке, `srand(seed)`, seed это 3-й аргумент

Строки результата в динамической памяти, `string.h` не используется.

## Алгоритм
- `calc_length`: счет символов до `'\0'`.
- `reverse_string`, `upper_odd_positions`: выделить `len + 1` байт, заполнить по индексам.
- `sort_by_char_class`: три прохода по строке (цифры, буквы, остальное).
- `concat_random_order`: массив индексов `0..count-1`, перемешивание Фишера-Йетса через `rand()` после `srand(seed)`, затем копирование строк в этом порядке.
- Seed разбирается вручную, только цифры, с проверкой переполнения `unsigned int`.
- Все функции возвращают `status_t`, результат отдают через параметры.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic -o task1 main.c`

## Тесты
| Команда | Результат |
|---|---|
| `./task1 -l "Hello, World"` | `12` |
| `./task1 -r Hello` | `olleH` |
| `./task1 -u abcdefgh` | `aBcDeFgH` |
| `./task1 -n "a1,b2 c3!"` | `123abc, !` |
| `./task1 -c A 42 B C D` | `DBAC` |
| `./task1 -c A 7 B C D` | `CDAB` |
| `./task1 -c x 42` | `x` |
| `./task1 -r ""` | пустая строка |
| `./task1 -l` | ошибка usage, код 1 |
| `./task1 -x abc` | ошибка unknown flag |
| `./task1 -l a b` | ошибка usage |
| `./task1 -c A -5 B` | ошибка invalid unsigned number |
| `./task1 -c A 99999999999 B` | ошибка invalid unsigned number |

Порядок для `-c` зависит от реализации `rand()` (результаты получены на glibc).

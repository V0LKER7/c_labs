# Задание 9. Конечность представления дроби в системе счисления

## Условие
Функция с переменным числом аргументов получает основание системы счисления и десятичные дроби из (0; 1) и для каждой определяет, имеет ли она конечное представление в этой системе.

## Алгоритм
- Число `double` не хранит десятичную дробь точно (0.1 это не 1/10), поэтому по значению и точности `eps` ищется обыкновенная дробь `p/q` с помощью цепной дроби: подходящие дроби считаются, пока `|x - p/q| <= eps`. Знаменатель ограничен `10^12`, иначе ошибка потери точности.
- Дробь `p/q` в несократимом виде имеет конечное представление в системе с основанием `b` тогда и только тогда, когда все простые делители `q` делят `b`. Проверка: пока `gcd(q, b) > 1`, делим `q` на этот `gcd`; конечное представление, если в итоге `q == 1`.
- Ответы возвращаются массивом `int` (1 конечное, 0 бесконечное), освобождает вызывающий код.
- Ошибки: основание меньше 2, `eps` вне (0; 1), число вне (0; 1), потеря точности.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic -o task9 main.c -lm`

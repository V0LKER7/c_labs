# Задание 9. Конечность представления дроби в системе счисления

## Условие
Функция с переменным числом аргументов для каждой переданной десятичной дроби (double из (0; 1)) определяет, имеет ли она конечное представление в системе счисления с заданным основанием.

## Алгоритм
- Дробь имеет конечное представление в основании b, если после сокращения все простые делители знаменателя делятся на b.
- Знаменатель находится цепной дробью: подходящие дроби h/k считаются, пока |x - h/k| < eps (eps параметр функции). Например, 0.1 даёт 1/10, 1/3 даёт 1/3.
- Проверка знаменателя q: пока gcd(q, base) > 1, q делится на этот gcd. Дробь конечна, если q стало равно 1.
- check_finite_fractions(eps, base, count, &results, значения...) возвращает массив int (1 конечная, 0 бесконечная).
- Валидация: значения строго в (0; 1), base >= 2, eps > 0.

Сборка: `gcc -std=c99 -Wall -Wextra -pedantic -o main main.c -lm`

## Тесты (вывод ./main, eps = 1e-9)
```
base 2:  0.5 finite, 0.1 infinite, 0.25 finite, 0.75 finite
base 10: 0.1 finite, 0.125 finite, 1/3 infinite, 0.2 finite
base 3:  1/3 finite, 0.5 infinite, 1/9 finite, 0.2 infinite
base 6:  1/3 finite, 0.5 finite, 0.1 infinite, 1/6 finite
base 10 со значением 1.5: error 3 (недопустимый аргумент)
```

# Задание 10. Переразложение многочлена по степеням (x - a)

## Условие
Функция с переменным числом аргументов получает точность eps, число a, указатель для записи динамического массива результата, степень n и коэффициенты f0..fn (double). Нужно найти g0..gn такие, что f(x) = f0 + f1 x + ... + fn x^n = g0 + g1 (x - a) + ... + gn (x - a)^n.

## Алгоритм
- Коэффициенты читаются через va_arg в динамический массив.
- Повторная схема Горнера (синтез деления на (x - a)): для i от 0 до n-1, для j от n-1 вниз до i выполняется c[j] += a * c[j+1]. После прохода c[i] равно gi.
- Коэффициенты, по модулю меньшие eps, обнуляются.
- Валидация: степень >= 0, eps >= 0, указатель результата не NULL.

Сборка: `gcc -std=c99 -Wall -Wextra -pedantic -o main main.c -lm`

## Тесты (вывод ./main)
| Многочлен | a | g0, g1, ... |
|---|---|---|
| 1 + 2x + 3x^2 | 1 | 6, 8, 3 |
| x^3 | 2 | 8, 12, 6, 1 |
| 5 - 3x + 2x^3 + x^4 | -1.5 | 7.8125, -3, 4.5, -4, 1 |
| 7 | 3 | 7 |
| степень -1 | 3 | error 3 |

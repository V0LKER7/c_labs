# Задание 10. Переразложение многочлена по степеням (x - a)

## Условие
Функция с переменным числом аргументов получает `eps`, значение `a`, указатель на место для результата, степень `n` и коэффициенты `f_0..f_n`. Нужно найти `g_0..g_n` такие, что `f(x) = g_0 + g_1 (x - a) + ... + g_n (x - a)^n`. Результат в динамически выделенном массиве.

## Алгоритм
Схема Горнера, многократное деление на `(x - a)` (сдвиг Тейлора), `O(n^2)`:
```
для i = 0..n:
    для j = n..i+1 (вниз):
        c[j-1] += a * c[j]
    g[i] = c[i]
```
Значения `g[i]`, по модулю меньшие `eps`, заменяются нулем. Ошибки: `eps < 0`, степень меньше 0, нехватка памяти.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic -o task10 main.c -lm`

## Тесты (вывод `./task10`)
```
1 + 2x + 3x^2 at a=1: g0=6 g1=8 g2=3
1 - 2x + x^3 at a=2: g0=5 g1=10 g2=6 g3=1
x^2 at a=0.5: g0=0.25 g1=1 g2=1
constant 5 at a=1: g0=5
negative degree: degree must not be negative
```
Проверка первого случая: `f(1) = 6`, `f'(1) = 8`, `f''(1)/2 = 3`.

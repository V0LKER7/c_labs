# Задание 3. Поиск подстроки в файлах

## Условие
Функция с переменным числом аргументов получает подстроку, число файлов и пути к ним. Для каждого файла нужно найти все вхождения подстроки (в ней могут быть пробелы, табы, переносы строк). Вывод: номер строки (с 1) и номер символа в строке (с 1). `strstr` и `strncmp` запрещены (`string.h` не используется вовсе).

## Алгоритм
- `find_in_files(&results, substring, file_count, path1, ...)` возвращает массив `file_result_t` (путь, статус файла, массив совпадений). Вывод делает `main`.
- Файл читается целиком в буфер (`fread`, рост буфера удвоением).
- Наивный поиск: для каждой позиции `i` посимвольное сравнение. Вхождения могут перекрываться. Номер строки и колонки обновляются на каждом символе (`'\n'` увеличивает строку и сбрасывает колонку).
- Ошибка открытия одного файла записывается в его статус, остальные файлы обрабатываются.
- Демонстрация поддерживает от 1 до 5 файлов (число аргументов вызова фиксируется на этапе компиляции, поэтому в `main` используется `switch`).

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic -o task3 main.c`

## Тесты
`f1.txt`: `abcabc\nxabcx abc\n  \tab\n`, `f2.txt`: `aaaa\nnothing here\n`, `f3.txt` пустой.

| Команда | Результат |
|---|---|
| `./task3 abc f1.txt f2.txt f3.txt nofile.txt` | f1: (1,1) (1,4) (2,2) (2,7); f2 и f3: no occurrences; nofile: cannot open file |
| `./task3 aa f2.txt` | (1,1) (1,2) (1,3), перекрытия учтены |
| `./task3 $'c\nx' f1.txt` | (1,6), подстрока с переносом строки |
| `./task3 $' \tab' f1.txt` | (3,2), пробел и табуляция |
| `./task3 $'\n' f1.txt` | (1,7) (2,10) (3,6) |
| `./task3 "" f1.txt` | ошибка: пустая подстрока |
| `./task3 abc` | ошибка usage |

`$'...'` работает в bash.

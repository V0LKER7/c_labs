# Задание 3. Поиск подстроки в файлах

## Условие
Функция с переменным числом аргументов: подстрока, количество файлов, пути. Для каждого файла находит все вхождения подстроки (в ней могут быть пробелы, табуляции, переводы строк). Для каждого вхождения выводятся номер строки и номер символа в строке (с 1). strstr и strncmp запрещены.

## Алгоритм
- find_in_files(list, substring, file_count, ...) читает пути через va_arg, не печатает, а складывает результаты в динамический список Match (файл, строка, столбец).
- Файл целиком читается в память через fread.
- Наивный поиск: для каждой позиции i побайтовое сравнение с подстрокой собственной функцией. Одновременно ведутся счётчики строки и столбца (на \n строка растёт, столбец сбрасывается в 1). Перекрывающиеся вхождения учитываются.
- Вывод выполняется отдельной функцией print_matches.
- Ошибка открытия файла возвращается статусом STATUS_FILE_ERROR.

Сборка: `gcc -std=c99 -Wall -Wextra -pedantic -o main main.c -lm`

## Тесты
main сам создаёт sample_1.txt ("abc abc\nabcabc\n\tabc  abc") и sample_2.txt ("hello\nworld\nlo wo\nlololo"), потом удаляет их.

| Подстрока | sample_1.txt | sample_2.txt |
|---|---|---|
| "abc" | 1:1, 1:5, 2:1, 2:4, 3:2, 3:7 | нет |
| "lo" | нет | 1:4, 3:1, 4:1, 4:3, 4:5 |
| "lo\nwo" | нет | 1:4 |
| два пробела | 3:5 | нет |
| "zzz" | нет | нет |
| "abc" и файл missing.txt | Error: cannot read one of the files | |

Формат: строка:столбец.

# Задание 4. Выбор файлов для резервного копирования

## Условие
Есть n файлов (имя, размер, важность) и накопитель вместимостью capacity. Выбрать набор с суммарным размером не больше capacity и максимальной суммарной важностью (каждый файл не более одного раза). Ввод из stdin: первая строка n и capacity, далее n строк "filename size importance". Вывод:
```
TOTAL_SIZE S
TOTAL_IMPORTANCE I
FILES k
<имена в порядке ввода>
```

## Алгоритм
- Задача о рюкзаке 0/1, динамика table[i][w] = максимальная важность первых i файлов при вместимости w.
- table[i][w] = max(table[i-1][w], table[i-1][w - size] + importance), если файл помещается.
- Восстановление ответа с конца: если table[i][w] != table[i-1][w], файл выбран и w уменьшается на его размер.
- Результат собирается в Backup_result в порядке ввода.
- Валидация: n > 0, capacity >= 0, size > 0, importance >= 0, имена уникальны, контроль переполнения размера таблицы и выделения памяти.
- Ввод (read_input), вычисление (select_backup_files) и вывод (print_result) разделены.

Сборка: `gcc -std=c99 -Wall -Wextra -pedantic -o main main.c -lm`

## Тесты
Ввод:
```
5 10
a 5 10
b 4 40
c 6 30
d 3 50
e 1 5
```
Вывод:
```
TOTAL_SIZE 8
TOTAL_IMPORTANCE 95
FILES 3
b
d
e
```

Ввод "2 1 / a 5 10 / b 4 40" (ничего не помещается):
```
TOTAL_SIZE 0
TOTAL_IMPORTANCE 0
FILES 0
```

Ввод с повторяющимся именем: Error: invalid input, код 1.

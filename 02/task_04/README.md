# Задание 4. Выбор файлов для резервного копирования

## Условие
Есть файлы с именем, размером и важностью, накопитель вместимости `capacity`. Нужно выбрать набор файлов с суммарным размером не больше `capacity` и максимальной суммарной важностью (каждый файл не более одного раза). Ввод со стандартного потока: `n capacity`, затем `n` строк `filename size importance`. Вывод:
```
TOTAL_SIZE S
TOTAL_IMPORTANCE I
FILES k
<имена в порядке ввода>
```

## Алгоритм
Задача о рюкзаке 0/1, динамическое программирование.
- `best[w]` максимальная важность при вместимости `w` (одномерный массив).
- Для каждого файла `i` и `w` от `capacity` до `size` вниз: если `best[w - size] + importance > best[w]`, обновить и поставить `take[i][w] = 1`.
- Восстановление: `w = capacity`, `i` от последнего к первому, если `take[i][w]`, файл выбран и `w -= size`.
- Результат `backup_result_t` (массив выбранных файлов, суммарный размер и важность) собирается в порядке ввода.
- Проверяется ввод (только неотрицательные числа, размер больше 0, уникальные имена), переполнение размеров таблицы и суммы важности.

## Сборка
`gcc -std=c99 -Wall -Wextra -pedantic -o task4 main.c`

## Тесты
| Ввод | Вывод |
|---|---|
| `5 10`, a 5 10, b 4 40, c 6 30, d 3 50, e 11 99 | `TOTAL_SIZE 7`, `TOTAL_IMPORTANCE 90`, `FILES 2`, b, d |
| `2 3`, big 5 100, big2 9 7 (ничего не помещается) | `0`, `0`, `FILES 0` |
| `1 0`, x 1 5 (нулевая вместимость) | `0`, `0`, `FILES 0` |
| `3 7`, x 3 4, y 4 5, z 2 3 | `TOTAL_SIZE 7`, `TOTAL_IMPORTANCE 9`, `FILES 2`, x, y |
| повторяющиеся имена, размер 0, нехватка полей, нечисловой ввод | ошибка invalid input data, код 1 |
